Aktivasi Auto-Klik di Dalam Kuis AlfaLearning

Secara bawaan, browser memblokir akses DOM langsung antar domain berbeda (Cross-Origin Security) saat memuat alfalearning.sat.co.id. Pilih salah satu dari 3 solusi nyata di bawah ini agar tombol ▶ PLAY AUTO-PILOT & AUTO-RUN KUIS langsung mengklik radio button di dalam kuis asli:

🏆 Solusi 1 (TERBAIK — Tanpa Ekstensi, Jalan di Chrome Android & PC)

Simpan file vercel.json ini sejajar dengan index.html saat deploy ke Vercel, lalu klik tombol Vercel Proxy (/alfa/) di toolbar JARVIS. Browser menjadi Same-Origin sehingga auto-klik berjalan 100% langsung tanpa ekstensi! 

{
  "rewrites": [
    { "source": "/alfa/:path*", "destination": "https://alfalearning.sat.co.id/:path*" }
  ]
}
🔌 Solusi 2 (Tampermonkey PC / Kiwi & Lemur Browser Android — Support Auto-Klik + Copy Soal)

Pasang 1x di Tampermonkey (Chrome/Edge PC atau Kiwi/Lemur Browser Android). Mendukung tombol ▶ PLAY AUTO-PILOT, tombol 📋 Copy Teks Soal, serta tombol mengambang di pojok kuis.
